# 历史追踪文档已归档

日期：2026-04-29

这份文档记录的是上一版讨论稿，已被新的返工方案替代。为避免继续误导新用户和审查流程，本文件只保留归档说明。

当前有效方案见：

- `docs/admin-gate-account-settings-refactor-2026-04-29.md`

当前有效结论：

1. 前端首屏是管理员登录页，输入管理员鉴权后才显示主界面。
2. 登录成功后默认拥有全部管理权限，不再在各个配置区重复填写管理员口令。
3. 设置页只保留全局生成、外观、图片存储、部署与备份。
4. API Key、ChatGPT OAuth、账号保存位置、Upstash、迁移和连接测试都放在独立账号管理里。
5. 设置页不再提供旧默认配置表单；API 地址在具体账号里填写。
6. 账号保存优先服务端或 Upstash，不可用时继续回退浏览器缓存。
7. 后台生成拿到明确上游错误时直接展示真实错误，不再按连接波动反复等待。
