# image-gen P4 产品增强路线

> 创建时间：2026-04-28 16:15 CST
> 来源：`docs/audit-p0-p3-tracking-2026-04-28.md` 的 P3.7
> 定位：P0-P3 稳定性、安全和维护性修复后的下一批产品增强 backlog。

## P4.1 局部编辑与画布工作流

- **目标用户**：需要对现有图片做局部重绘、擦除、裁剪和二次构图的用户。
- **建议优先级**：P4-High
- **推荐实现**：
  1. 新增轻量 canvas 编辑器，支持画笔/橡皮、撤销、清空 mask。
  2. 支持裁剪、固定比例和导出参考图 + mask。
  3. 复用现有 Images edits JSON/multipart 兼容链路，不新增敏感后端聚合。
- **验收标准**：
  - 移动端和桌面端都能绘制 mask。
  - mask 缺少参考图时仍被阻止。
  - 历史图片可一键进入编辑器继续图生图。

## P4.2 上传增强

- **目标用户**：移动端和桌面端频繁使用参考图的用户。
- **建议优先级**：P4-High
- **推荐实现**：
  1. 支持拖拽上传、粘贴图片、移动端拍照入口说明。
  2. 上传前展示尺寸、格式、大小和压缩后体积。
  3. 多参考图排序和删除更明确。
- **验收标准**：
  - 拖拽/粘贴/文件选择都会进入同一预处理链路。
  - 仍遵守最多 3 张和总大小限制。

## P4.3 队列面板

- **目标用户**：批量生成、对比模式和弱网环境用户。
- **建议优先级**：P4-High
- **推荐实现**：
  1. 新增任务队列面板，展示 pending/running/success/failed/cancelled。
  2. 支持单任务取消、重试、放弃、复制错误。
  3. 对比模式每个组合展示独立进度。
- **验收标准**：
  - 刷新页面后能恢复未完成任务。
  - 取消和重试不会重复提交已创建任务。

## P4.4 历史增强

- **目标用户**：长期使用并管理大量图片的用户。
- **建议优先级**：P4-Medium
- **推荐实现**：
  1. 历史分页/无限滚动。
  2. 按账号、模型、尺寸、时间、收藏、标签筛选。
  3. 批量收藏、批量删除、批量导出。
- **验收标准**：
  - 大量历史记录下页面不卡顿。
  - 删除仍只影响数据目录内文件。

## P4.5 对比报告导出

- **目标用户**：评估多个账号、模型或参数组合效果的用户。
- **建议优先级**：P4-Medium
- **推荐实现**：
  1. 对比结果按账号/模型/耗时/错误汇总。
  2. 支持导出 HTML/Markdown 报告。
  3. 每个组合可复制 prompt、参数和诊断摘要。
- **验收标准**：
  - 报告不包含 API Key、OAuth token 或管理口令。
  - 失败组合有可读失败原因。

## P4.6 诊断与可观测性增强

- **目标用户**：自托管、云部署和排障用户。
- **建议优先级**：P4-Medium
- **推荐实现**：
  1. 一键复制脱敏诊断信息。
  2. 展示最近一次成功链路、失败链路、上游 host、状态码、耗时。
  3. Docker/Node/serverless 能力检测面板。
- **验收标准**：
  - 诊断信息不包含 token、cookie、完整密钥或本地敏感路径。
  - 支持用户粘贴到 issue 时安全排障。

## P4.7 统计面板

- **目标用户**：关注成本、速度和成功率的重度用户。
- **建议优先级**：P4-Low
- **推荐实现**：
  1. 按账号、模型、尺寸统计成功率和平均耗时。
  2. 可选成本估算字段，由用户手动配置单价。
  3. 本地存储统计，不上传。
- **验收标准**：
  - 默认不展示敏感账号 key。
  - 清理数据时统计也能按范围清理。
