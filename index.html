账号保存位置

Node / Docker 将优先保存到服务端账号存储；云平台配置 Upstash 后保存到远程存储；未配置时继续保存到当前浏览器。

当前浏览器缓存 当前部署未检测到可用的服务端账号存储或 Upstash，API Key 与 OAuth 账号会按旧逻辑保存在此浏览器。 敏感字段：仅保存在当前浏览器；换设备、无痕模式或清理浏览器数据后需要重新配置。
管理员登录并启用服务端账号存储后，可以把当前浏览器账号迁移到服务端。
迁移不会自动清空浏览器副本；这样即使服务端存储暂时不可用，也能继续沿用旧缓存。

账号存储配置

云平台不适合依赖本地文件保存账号时，可选择 Upstash。保存后敏感字段不会回显；留空会保留已有配置，未配置完整则自动回退浏览器缓存。
保存服务端配置后，账号会优先写入可用的服务端或 Upstash 存储。
